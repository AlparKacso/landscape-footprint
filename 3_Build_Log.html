Build log

Eight hours across six days and three prototypes — V1 steered and too complex to pitch, V2 built autonomously as a control, V3 the merge that shipped.

What I built

  • Four CSVs become a scored model; 106 custom objects become eleven funded decisions — twelve ordered rules, a four-state evidence model, an agent that writes words and never numbers.

What I tried

  • A second prototype built by the agent unsupervised, as a control. Two ideas survived it; the engine did not.
  • Dropping file upload — wrong. A pipeline nobody sees run is not trusted; it came back as a page.

What failed

  • A split cache, twice, on the deployed copy — fresh page, stale module, dead on boot. An import map now pins all thirteen.
  • The treemap rendered blank on first view — it measures a container with no box while hidden.

What I cut

  • A risk dial (0–100). Nobody says “I accept 70”. Now a hard engine guarantee — identical output.
  • A per-object browser. The eleven decisions exist to replace exactly that list.
  • Effort and cost estimates. No size signal in the extract; any figure would be invented.
  • The Extract Wizard — three steps proving the one thing nobody doubts.
